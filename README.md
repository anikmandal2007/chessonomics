Chessonomics ♟️

A Statistical and Game-Theoretic Study of Economic Decision-Making Through Chess

📌 Project Overview

Chessonomics explores the connection between Economics, Chess, Statistics, Probability, and Game Theory.

The project uses chess-based examples to demonstrate how economic concepts such as opportunity cost, expected value, risk, strategic decision-making, and Nash equilibrium can be understood through simplified chess scenarios.

🎯 Project Objectives

- Understand economic decision-making through chess.
- Apply probability and expected value calculations.
- Analyse risk using variance and standard deviation.
- Explore strategic interactions using Game Theory.
- Use Python for statistical analysis and data visualisation.

🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib
- GitHub

📊 Current Project Features

1. Chess piece material valuation.
2. Opportunity cost analysis.
3. Expected value calculations.
4. Risk and uncertainty analysis.
5. Game Theory payoff matrix.
6. Nash equilibrium identification.
7. Win, draw, and loss percentage analysis.
8. Statistical analysis of chess game lengths.
9. Data visualisation using charts.
10. CSV data export.
